# F3 — 手机 → Mac 中继

## Summary
- 无高度重合的「Android QQ Music → Mac 悬浮歌词」完整产品；常见模式是 **WebNowPlaying / HTTP JSON now-playing** 再由桌面端搜词。
- 正确分工：**桌面歌词 UI/搜词用 lyrimuse（本机播放）**；手机场景保留轻量 POST `/api/now-playing` 中继（本仓库 `android/PhoneLyricsRelay`）。
- 不要把自研 Electron 壳当成 lyrimuse 的替代品。
