# F2 — Now Playing / 歌词数据源

## Summary
- 成熟 Mac 歌词 App 用系统 **MediaRemote**（私有，经 media-control/内部通道）读本机播放器 Now Playing，再按 title+artist 多源搜 LRC。
- **QQ 音乐 Mac 客户端**会上报 MediaRemote；AppleScript 基本不可用（`tell application "QQMusic"` 失败）。
- QQ 官方歌词搜索 API 已失效（LyricsX #601）；可靠源：Kugou / 多源（lyrimuse 十源含 Deezer）。
- 手机 QQ 音乐 **不会** 出现在 Mac MediaRemote —— 必须 LAN 中继。
