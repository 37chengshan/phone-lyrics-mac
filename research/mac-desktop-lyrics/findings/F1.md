# F1 — 成成熟 Mac 桌面歌词项目

## Summary
- **lyrimuse**（Yudaotor）: 2026-09 仍活跃，Swift，明确支持 QQ 音乐 + 悬浮窗 + 菜单栏 + 灵动岛；Apple Silicon 安装包 `Lyrimuse-v1.7.0-macos.zip`（~17MB），GPL-3.0。社区共识的 LyricsX 替代。
- **LyricsX**: 曾是标准答案，作者停更；Sonoma/Sequoia 大量 open issue；QQ 歌词 API 已挂。不推荐新装官方包。
- **LyricFever / LyricFever-Lite**: 主打 Spotify/Apple Music，对 QQ 音乐弱。
- **结论**: Mac 本机桌面歌词 **直接装 lyrimuse**，不要自研对等实现。
